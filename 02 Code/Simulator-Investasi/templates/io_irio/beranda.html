Kuadran keterkaitan: ke belakang × ke depan

Kanan atas = sektor kunci (menarik dan mendorong sektor lain di atas rata-rata). Ukuran titik = output. Garis putus = rata-rata (1).

Multiplier per sektor

Multiplier output = tambahan output seluruh ekonomi per Rp1 permintaan akhir sektor; multiplier NTB = tambahan nilai tambah.

Multiplier output menurut tahun

Klik nama sektor di legenda untuk menyembunyikan. Semua tahun tabel dengan metode terpilih.

Jaringan sektor

Busur dari sektor pemasok ke sektor pembeli bila koefisien input A ≥ ambang; tebal ∝ koefisien. Ukuran simpul ∝ output.
